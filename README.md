# Arena Defender



is a 2D fighting game created using monogame and c# language.

the game is originally designed for the player to move around, making sure they survive as bullets are fired automatically to the closest enemy.



As waves increases, so does the game become more and more difficult



### How to run and play the project

1. git clone https://github.com/Darcy-02/ArenaDefender.git
2. cd ArenaDefender
3. cd ArenaDefender.Game
4. make sure you have dotnet installed (i used SDK 9.0)
5. run "dotnet run" in the terminal
6. then you'll see a display of the game terminal 
7. click enter to enter the game play
8. use WASD arrows to move the player around
9. keep playing
10. if you lose and want to play again click enter again
